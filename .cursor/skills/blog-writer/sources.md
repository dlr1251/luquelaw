## Press (context)

El Tiempo, El Espectador, Semana, La Silla Vacía, Portafolio, Bloomberg Línea, El Colombiano. Note date and whether they cite a numbered norm.

## X (signal only)

Search the topic plus handles such as:

- `MigracionCol`
- `CancilleriaCol`
- `MinjusticiaCo`
- `CConstitucional`
- `infopresidencia`
- `MigracionCol` regional accounts if the story is local

Record: handle, post date, URL, claim in one line, **confirmed by official/press? yes/no**.

Do not scrape login-walled X as if it were a primary source. If fetch fails, say the scout is incomplete on X.

## Query patterns

Combine Spanish legal names with English reader terms:

- `visa Colombia` + `Migración` + year
- `PPT` / `PEP` / `visa de nómada` / `visa de inversionista` / `cédula de extranjería`
- `Decreto` / `Resolución` + number if known
- `reforma migratoria Colombia` / `proyecto de ley` + inmigración

Drop results that are visa-mill ads or unsourced Telegram dumps.
